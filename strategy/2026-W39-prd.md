# W39 PRD — Subwise: Gizlilik-Öncelikli Abonelik Takipçisi

**Kaynak rapor:** `research/2026-W38-market-report.md` (2026-09-14)
**Seçim:** Aday #1 — Gizlilik-öncelikli abonelik/yenileme takipçisi (manuel, cross-platform), skor 23/25
**Çalışma başlığı:** Subwise · slug `subwise` · scheme `subwise` · iOS `com.subwise.app` · Android `com.subwise.app` (isim mühendislikte değişebilir)
**Hedef hafta:** W39 (Pazartesi–Cuma: scaffold → state/db → UI → verification; store submit kullanıcı onayı olmadan YOK)

## 1. Hedef kullanıcı

Ayda 5–15 dijital aboneliği (streaming, müzik, bulut, oyun, VPN, dergi, uygulama abonelikleri) olan, banka hesabını üçüncü parti uygulamaya bağlamak istemeyen 18–45 yaş iOS/Android kullanıcısı. Tek cümlelik çekirdek döngü: **aç → toplam aylık maliyeti gör → yenilemesi yaklaşanı fark et → kapat (<10 sn).**

## 2. Problem

- Abonelikler farklı günlerde yenileniyor; kullanıcı toplam ne ödediğini bilmiyor, "sessiz yenileme" ile para kaybediyor.
- Mevcut çözümler ikiye ayrılıyor ve ikisi de eksik: Bobby yalnızca iOS + tek alımlık (CNBC Select 2026; getfinny 2026); Rocket Money banka erişimi zorunlu, ücretsiz katmanı kısıtlı, $6–12/ay, ABD dışı kapsamı zayıf (subtracker.io 2026). Reddit r/ProductivityApps 2026: "Rocket Money kalabalık, Bobby'da pazarlık yok".
- Boşluk: Android'de temiz, gizli, manuel, cross-platform tracker yok. Rapor skoru: K5·B5·P4·E5·X4 = 23/25.

## 3. Farklılaşan MVP kapsamı (1 hafta, YAGNI)

MVP = rapordaki tanımın birebiri: **liste + ekleme formu + local notification + toplam + CSV export.** Banka bağlantısı YOK, fatura OCR YOK, hesap/ backend YOK.

- Abonelik CRUD: ad, tutar, para birimi (TRY/USD/EUR/GBP seçimi), fatura dönemi (haftalık/aylık/3 aylık/6 aylık/yıllık), sonraki yenileme tarihi, renk + ikon (emoji seçici), not.
- Dashboard: para birimi başına gruplanmış toplam (aylık eşdeğer + dönemlik toplam). Canlı kur ÇEKME YOK — farklı para birimleri ayrı satırda toplanır (`// ponytail: kur çevrimi yok, serbest API anahtarı isteyince eklenir`).
- Yenileme uyarıları: local notification; aylık ve daha sık dönemlerde 1 gün önce, 3 aylık+ dönemlerde 7 gün + 1 gün önce, yıllıkta 7 gün + 1 gün önce (raporun "yıllıkta erken haber" şartı).
- 60 saniyelik ilk-açılış sihirbazı: 3 adım (1: hazır şablonlardan sahip olduklarını işaretle — Netflix, Spotify, YouTube Premium, iCloud+, PlayStation Plus, Game Pass, VPN şablonu; 2: tutarları düzelt; 3: bildirim izni iste) → dashboard. Bu, raporun "manuel giriş sürtünmesi" riskini karşılayan ana mekanik.
- CSV dışa aktarım: `Share.shareAsync` ile `abonelikler.csv` (`name,price,currency,cycle,nextRenewal`).
- Dil: TR + EN (custom `t()` + `strings.ts`; `react-i18next` YOK).
- Ücretsiz limit: 10 abonelik; üstü paywall ekranı gösterir (ödeme altyapısı MVP'de stub — bkz. §7).

## 4. Ekran akışı (4 ekran, expo-router)

1. **Onboarding wizard** (`app/onboarding.tsx`, 3 adım, yalnızca ilk açılışta; AsyncStorage `hasOnboarded` flag'i): şablon seç → tutar düzelt → bildirim izni → `replace('/')`.
2. **Dashboard/Liste** (`app/index.tsx`): üstte toplam kartları (para birimi başına), altta yenileme tarihine göre sıralı liste; her satır: ikon, ad, tutar/dönem, "X gün kaldı" rozeti; FAB → ekle formu; satıra dokun → detay.
3. **Ekle/Düzenle** (`app/subscription/[id].tsx`, yeni kayıtta `new` id'si): ad, tutar (sayısal klavye), para birimi (4 seçenek), dönem (5 seçenek), tarih (native date picker), renk+emoji, not, kaydet/sil.
4. **Ayarlar** (`app/settings.tsx`): dil (TR/EN), bildirim aç/kapat, CSV export, limit/paywall bilgisi, gizlilik metni (yerel veri, hesap yok).

Akış: onboarding → dashboard ⇄ ekle/düzenle → dashboard; ayarlar tab'dan. Sekme çubuğu: Liste + Ayarlar (2 sekme; raporun 3–6 ekran örüntüsüne uygun).

## 5. Non-goals (W39'da YAPILMAYACAK)

- Banka/ekstre bağlantısı, kart tarama, fatura OCR, e-posta tarama.
- Kullanıcı hesabı, bulut senkron, backend/Supabase, analitik SDK.
- Otomatik fiyat takibi ("Netflix zam yaptı" uyarısı), kur çevrimi, bütçe grafikleri, widget.
- Aile paylaşımı (paywall vaadi olarak metinde geçer, kodlanmaz).

## 6. Teknik plan (Expo / React Native)

- **Baz:** Expo SDK v57.0.0 (AGENTS.md kuralı: koda başlamadan https://docs.expo.dev/versions/v57.0.0/ ilgili sayfaları oku). TypeScript `strict: true`. Blank template (tab gerekmez, 2 ekranlı yapı `expo-router` ile elle).
- **Klasör (expo-init-checklist minimali):** `app/` (ince screen'ler: `index`, `onboarding`, `settings`, `subscription/[id]`) · `src/components/` (SubscriptionRow, TotalCard, PaywallSheet) · `src/db/` (`schema.ts` + `storage.ts`; AsyncStorage üstünde tek JSON key `subwise:v1`; migration: version key kontrolü, yoksa boş liste) · `src/state/` (`useSubscriptions.ts`, zustand + persist yok, AsyncStorage manuel load/save) · `src/i18n/` (`strings.ts` + `t(lang,key)`, anlamsal anahtar `sub.list.title`) · `src/lib/` (`renewals.ts`: sonraki-yenileme hesabı + bildirim zamanlaması; `csv.ts`: CSV üretimi) · `__tests__/` (`renewals.test.ts`, `csv.test.ts`, `fixtures.ts`).
- **Veri modeli:** `Subscription { id: string (uuid v4, `uuid` paketi YOK — `Math.random().toString(36)` + Date.now), name: string, price: number (>0), currency: 'TRY'|'USD'|'EUR'|'GBP', cycle: 'weekly'|'monthly'|'quarterly'|'semiannual'|'yearly', nextRenewal: string (ISO date), color: string (hex), icon: string (emoji), notes: string }`.
- **Bildirim:** `expo-notifications` local schedule; her kaydetmede ilgili aboneliğin eski bildirimi iptal + yenisi planla (fonksiyon: `scheduleRenewalReminders(sub): Promise<string[]>` — notification id listesi döner, abonelikle birlikte saklanır).
- **Bağımlılık disiplini:** `zustand` + `expo-notifications` + `expo-sharing` (CSV) dışında yeni dep YOK. `drizzle-orm`/`expo-sqlite` YOK (liste <1000 öğe; AsyncStorage yeter — ponytail tavanı kodda işaretle). `tanstack-query` YOK (remote fetch yok). `react-i18next` YOK.
- **Tema:** `src/theme.ts` tek dosya (renk, spacing, radius); açık tema only (koyu tema non-goal).

## 7. Monetizasyon

Freemium: 10 aboneliğe kadar ücretsiz, sınırsız + erken-uyarı rozeti + CSV export yıllık küçük ücretle (`LIMIT_FREE = 10` sabiti, `src/lib/constants.ts`). Rakip altı oyulabilir bant: Rocket Money/Copilot $8–13/ay bandının belirgin altı, yıllık tek fiyat. **MVP kararı:** ödeme SDK'su (RevenueCat) W39'da ENTEGRE EDİLMEZ; limit aşımında paywall ekranı "Çok yakında" metniyle gösterilir ve satın alma butonu devre dışıdır (`// ponytail: RevenueCat entegrasyonu ödeme onayı sonrası`). Gerekçe: store submit zaten onay gerektiriyor; IAP'siz binary review riski alınmaz, fiyatlandırma kullanıcı onayıyla netleşir.

## 8. Gizlilik / politika riskleri

- **Veri toplamama:** finansal veri cihazdan çıkmaz; hesap yok, backend yok, analitik yok → App Store Privacy Nutrition Label: "Data Not Collected". `PRIVACY.md` bunu yazar.
- **Bildirim izni:** iOS'ta onboarding 3. adımda istenir, reddedilirse uygulama tam çalışır (uyarı rozeti "bildirim kapalı" notu gösterir) — reddi cezalandırma yok.
- **Yanlış alarm riski:** kullanıcı tarihi yanlış girerse bildirim yanlış günde gelir; hafifletme: kaydetmeden önce "Sonraki yenileme: 12 Eki 2026, Pazar" önizleme satırı zorunlu gösterilir.
- **Politika:** IAP'siz paywall "yakında" ekranı review'da sorun çıkarmaz (satın alma akışı yok, external link yok). RevenueCat eklenince §7 güncellenir.
- **İzinler:** yalnızca `expo-notifications` (local). Konum/kamera/kişiler YOK.

## 9. Test kabul kriterleri (W39 çıkışı için hepsi yeşil)

1. `npx expo-doctor` temiz.
2. `npx tsc --noEmit` = 0 hata.
3. `npx jest --ci`: `renewals.test.ts` (aylık abonelikte sonraki yenileme = +1 ay; yıllıkta bildirim zamanları [7 gün, 1 gün] önce; geçmiş tarih girilirse bugüne çekilir), `csv.test.ts` (Türkçe karakter + virgüllü not escape edilir) — tamamı PASS.
4. Manuel: onboarding 60 sn altında tamamlanır, 3 şablon seçilip dashboard'da görünür; uçak modunda tüm akış çalışır (offline-first kanıtı); bildirim izni reddedilince liste/form bozulmaz.
5. TestFlight / internal track build'i kullanıcı onayı olmadan DENENMEZ (`.env`/EAS secret'ları chat'e yazılmaz).

## 10. Mağaza konumu

- **Kategori:** Finance (birincil). **Yaş:** 4+. **Anahtar kelimeler:** subscription tracker, abonelik takip, renewal reminder, yenileme hatırlatıcı, offline (Bobby/Rocket Money'den ayrışan: "no bank login, offline, Android + iOS").
- **Açıklama kancası (EN):** " every subscription, one total. No bank login — your data never leaves your phone." (TR karşılığı aynı dosyada).
- **Ekran görüntüleri planı:** dashboard toplam kartı, ekle formu, bildirim örneği (3 kare).
- **Fiyat:** ücretsiz + yıllık IAP (tutar kullanıcı onayıyla; MVP'de kapalı).
